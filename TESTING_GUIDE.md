## 2) Запуск backend (рекомендуется)

Backend усиливает анализ. Без него расширение всё равно работает на локальных эвристиках.

### Вариант А — одним файлом

1. Открой папку `phishguard-extension\backend`
2. Дважды кликни `start.bat`
3. Оставь чёрное окно открытым
4. В браузере открой: http://127.0.0.1:8787/health  

Должно быть примерно:

```json
{"ok":true,"service":"legion-backend","version":"0.5.0", ...}
```

### Вариант Б — вручную в терминале

```bat
cd c:\Users\tigra\Downloads\phishguard-extension\backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8787
```

Если порт занят / старая версия отвечает — закрой старое окно uvicorn и запусти снова.

## 3) Установка расширения

1. Открой страницу расширений:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
2. Включи **Режим разработчика** (справа сверху)
3. Нажми **Загрузить распакованное расширение**
4. Выбери папку:

   `c:\Users\tigra\Downloads\phishguard-extension`

5. Закрепи иконку **Legion** на панели браузера
6. После каждого нашего обновления кода на этой странице жми **Обновить** (круглая стрелка на карточке Legion)

### Важно для демо-файлов `file://`

На карточке Legion → **Подробности** → включи:

**Разрешить доступ к URL-адресам файлов** / **Allow access to file URLs**

Иначе `demo\*.html` с диска не просканируются.

## 4) Первый взгляд на интерфейс

1. Открой любой сайт, например https://example.com  
2. Кликни иконку **Legion**

Ты увидишь:

- статус текущей вкладки
- строку **Backend: online / offline**
- кнопку **Показать демо-предупреждение**
- кнопку **Настройки**

Проверка демо-оверлея:
1. Оставайся на обычном http(s) сайте (не на `chrome://`)
2. Нажми **Показать демо-предупреждение**
3. Страница должна накрыться красным предупреждением
4. **Всё равно продолжить** — оверлей закрывается

## 5) Что проверить в предварительном тесте (чеклист)

### Тест A — доверенный сайт (должно быть тихо)

1. Открой https://yandex.ru или https://vk.com  
2. Открой попап Legion  

Ожидание:
- статус вроде **Доверенный сайт**
- этап **белый список**
- на иконке зелёная **`✓`**
- предупреждения нет

### Тест B — обычный логин (форма есть, паники нет)

1. Открой файл:

   `c:\Users\tigra\Downloads\phishguard-extension\demo\normal-login.html`

   (или перетащи его в окно браузера)

2. Убедись, что включён доступ к file URLs  
3. Обнови страницу  
4. Открой попап  

Ожидание:
- форма найдена
- на иконке жёлтая **`?`** (tier A: неизвестный сайт просит пароль)
- **оверлея нет**  
  (именно так и задумано: форма ≠ угроза, экран не блокируем)

Для сравнения открой `demo\soft-email-only.html` — там только email
без доп.сигналов, и должна быть зелёная **`✓`**.

### Тест C — учебный фишинг (должно предупредить)

1. Открой:

   `c:\Users\tigra\Downloads\phishguard-extension\demo\fake-phish.html`

2. Обнови страницу  

Ожидание:
- полный экран-предупреждение Legion
- причины вроде: таймер / компенсация / пароль от Госуслуг / brand spoof
- кнопки **Уйти** и **Всё равно продолжить**

### Тест D — backend статус

В попапе:
- если `start.bat` запущен → **Backend: online · LLM off · SB off**
- если не запущен → **Backend: offline** (локальные эвристики всё равно работают)

## 6) Настройки (по желанию)

Иконка Legion → **Настройки**:
- защита вкл/выкл
- строгость
- URL backend (`http://127.0.0.1:8787`)
- свой белый список (по одному домену в строке)
- кнопка **Проверить backend**

Пока **не включай** «Демо: всегда предупреждать на формах» для честного теста — иначе любой логин будет орать.

## 7) Ключи (позже, не для первого теста)

Когда будут готовы:

1. Скопируй `backend\.env.example` → `backend\.env`
2. Впиши:

```env
SAFE_BROWSING_API_KEY=...
LLM_API_KEY=...
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

3. Перезапусти `start.bat`  
4. В попапе должно стать `SB on` / `LLM on`

Инструкция по Google-ключу: `backend\SAFE_BROWSING_SETUP.md`  
По Safe Browsing помогу отдельно пошагово, когда скажешь «давай ключ».

## 8) Типичные проблемы

| Проблема | Что сделать |
|----------|-------------|
| Нет иконки | Закрепи расширение на панели |
| Демо-оверлей не показывается | Открой обычный сайт, не `chrome://extensions` |
| `demo/*.html` не сканируется | Включи Allow access to file URLs |
| Backend offline | Запусти `backend\start.bat`, проверь /health |
| Старая версия backend | Закрой окно uvicorn и запусти заново |
| Код обновили, а в браузере старое | На `chrome://extensions` нажми Обновить у Legion |
| После «Продолжить» снова не орёт | Нормально для этой вкладки/домена: отметка живёт в session-хранилище |
| Бейдж остался серым `·` | Сканер не прочитал страницу — нажми **Пересканировать** в попапе |
| Бейдж висит `…` | Страница ещё грузится; если надолго — «Пересканировать» |

---

## 8.1) Автопрогон перед показом

```bat
demo\run-checks.bat
```

Должно быть `LOGIC-PASSED`-набор из `OK` и строка `16/16 passed` по логике
плюс `14/14 passed` по backend. Если что-то `FAIL` — на демо лучше не идти.

Проверяются, среди прочего, бывшие ложные срабатывания:
- слова «доставка / заявка / ставка» больше не считаются упоминанием ВК;
- слово «пароль» в тексте справки не считается полем пароля;
- поддомен на площадке пользовательского контента не наследует доверие.
