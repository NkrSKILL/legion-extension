# Legion

Браузерное расширение (Chrome / Edge / Brave) + FastAPI backend.
Доп.защита от фишинга-однодневок. **Не замена антивируса.**

Стек: [TECH.md](TECH.md)

## Быстрый старт

### Backend

```bat
cd backend
start.bat
```

Проверка: http://127.0.0.1:8787/health

Ключи (опционально): скопируй `backend/.env.example` → `backend/.env`

- `SAFE_BROWSING_API_KEY` — Google Safe Browsing
- `LLM_API_KEY` — для серого коридора

`backend/.env` в `.gitignore` и в расширение не попадает. Если ключ куда-то
утёк (скриншот, чат, репозиторий) — отзови его в Google Cloud и выпусти новый,
а самому ключу поставь ограничение только на Safe Browsing API.

### Расширение

1. `chrome://extensions` → режим разработчика  
2. Загрузить распакованное → эта папка  
3. Обновить расширение после изменений кода  

Без backend Legion работает на локальных эвристиках.  
С backend включаются Safe Browsing (если ключ есть) и усиленный анализ.

## Индикатор на иконке

Статус есть всегда — «ничего не горит» быть не должно.

| Бейдж | Значение |
|-------|----------|
| `…` серый | идёт проверка |
| `✓` зелёный | whitelist или угроз не найдено |
| `?` жёлтый | осторожность (tier A или B), экран не блокируется |
| `!` красный | подтверждённый риск + оверлей |
| `·` серый | «продолжил на свой риск» или страницу не удалось проверить |

## Жёлтый режим

- **Красный** — Safe Browsing / blacklist / brand spoof **с подтверждением** / высокий risk / критичные поля + чужой origin
- **Жёлтый** — неизвестный сайт + критичные поля (A) или мягкие ПДн + доп.сигнал (B)
- **Зелёный** — whitelist или нет оснований для осторожности

## Проверки

```bat
demo\run-checks.bat
```

Прогоняет три группы:

- **синтаксис и загрузка модулей** расширения (headless Chrome, `demo/_syntax-check.html`);
- **логику протокола** — whitelist / exactDomains / красный / жёлтый и отдельно набор
  бывших ложных срабатываний (`demo/_logic-check.html`);
- **backend** — эвристики, brand spoof, `/health`, `/v1/analyze`, урезание URL для Safe Browsing
  (`backend/tests/run_checks.py`).

Живой UI браузера автотестами не покрыт — его смотрим руками по `TESTING_GUIDE.md`.
