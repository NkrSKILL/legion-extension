# Жёлтый режим Legion

## Статусы

| Статус | Бейдж | Когда |
|--------|-------|--------|
| pending | серый `…` | идёт проверка страницы |
| safe | зелёный `✓` | whitelist или нет оснований для осторожности |
| caution | жёлтый `?`, без оверлея | см. ниже |
| danger | красный `!` + оверлей | сильные улики |
| continued / unknown | серый `·` | «продолжил на свой риск» / страницу не удалось прочитать |

## Жёлтый tier A
Неизвестный сайт + критичные поля: password / card / govId / otp.

Критичность определяется **только реальными полями ввода**. Слово «пароль»
в тексте справочной модалки в tier A не попадает — иначе страница помощи
давала предупреждение на ровном месте.

## Жёлтый tier B
Мягкие ПДн (email / phone / name) или признаки формы входа в тексте **и**
хотя бы один доп.сигнал:
- lookalike домена к известному бренду (расстояние Дамерау—Левенштейна ≤ 1–2 либо бренд отдельным токеном в домене)
- упоминание бренда на чужом домене
- form action на другой origin (учитываются только формы с ПДн)
- HTTP (не localhost)

## Повышение до красного
- Safe Browsing / blacklist
- brand spoof **+ подтверждение**: lookalike, cross-origin, HTTP или текстовые маркеры давления
- высокий risk эвристик/LLM
- критичные поля + form cross-origin

Одно упоминание бренда красный не даёт: «Доставка Ozon» на обычном магазине
с формой входа раньше приводила к блокирующему оверлею.
